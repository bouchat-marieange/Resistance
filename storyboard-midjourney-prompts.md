## RAPPEL PARAMETRES MIDJOURNEY

| Parametre | Valeur | Raison |
|-----------|--------|--------|
| `--ar 16:9` | Format paysage cinematique | Standard video |
| `--style raw` | Rendu brut fidele au prompt | Evite l'embellissement MJ |
| `--s 200` | Stylisation moderee | Coherence entre images |
| `--v 6.1` | Version moteur | Meilleur rendu cinematique |
| `--sref [URL]` | Reference de style | A ajouter avec ton image de reference |
| `--cref [URL]` | Reference de personnage | A utiliser des que Raya apparait (09-20, 28-29, 35-42, 46-48) pour maintenir son apparence |
| `--no` | Exclusions | Ajouter `--no text words letters watermark` si du texte parasite apparait |

### Conseil workflow
1. Generer d'abord les images 05 et 09 pour etablir le visage de Raya
2. Utiliser `--cref` avec ces images pour tous les plans ou elle apparait
3. Generer les plans de cocoon ensemble (31-42) pour coherence de decor
4. Generer les plans de ville ensemble (07-20) pour coherence de decor
5. Les plans POV mains (35, 36, 39, 41, 42, 44, 47) peuvent etre generes en batch
